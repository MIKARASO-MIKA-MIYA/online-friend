# 🎮 F.R.I.E.N.D. - ARG Horror Game

Интерактивная браузерная хоррор-игра в стиле ретро-консоли / веб-терминала.

## ⚠️ Дисклеймер
- Это **театральная хоррор-игра**, все пугающие эффекты — вымысел.
- Данные о системе и примерном местоположении (страна, город) определяются через публичные IP API и встроенные функции браузера исключительно для создания драматического эффекта.
- Никнейм и вводные данные указываются **самим игроком** в рамках игрового процесса.
- **НИ КАКИЕ данные не отправляются на внешний сервер** — вся обработка происходит локально в браузере.
- Проект создается в исключительно развлекательных целях.

## 🎯 Технические особенности
- **Публичные IP API** — безопасное определение базовых сетевых параметров (город, IP).
- **Local / Session Storage** — сохранение прогресса локально на устройстве игрока.
- **Visual FX** — DOM-стилизация, имитация системных ошибок и глитчи на чистом HTML/CSS/JS без использования вредоносного ПО.

## 🚀 Запуск
1. Склонируй репозиторий.
2. Открой `index.html` в любом современном браузере или задеплой проект на **Vercel** / **GitHub Pages**.
